# 小程序今日工作台

公司介绍仍是初次打开的页面；登录后进入工作台。底部保留五个入口：工作台、助手、机器、订单、我的。公司介绍也可从“我的”查看。

工作台有交期风险、今日待办、待出货三个视图，可按订单号、工件或关联机器搜索，下拉刷新，20 条一页。精确匹配机器编号时优先按该机器筛选，避免 CNC-01 同时匹配到 DEMO-CNC-013 这类订单号。统计数字来自全部匹配订单，不是当前页的条数。

## 计算规则

- 范围：当前登录账号所属工厂、未关闭且未标记完成的订单。
- 时间：北京时间自然日。交期早于今天为逾期，今天至三天后（含）为临期。
- 进行中、仍有加工需求（或计划未设置）的订单，距最近报工满三个自然日提示跟进；无报工时从订单创建日期计算。此提醒不等于确认停产。
- 尚需加工的订单关联维护或停用机器时提示核实设备影响，不自动认定整单无法生产。
- 今日待办按订单去重，汇总上述风险、待开发/加工、缺交期/计划、待出货和出货达标待关单等事项。待办实时派生，没有持久化的分派或手动完成状态。
- 剩余待加工 = max(计划 - 累计加工, 0)；剩余待出货 = max(计划 - 累计出货, 0)。未设计划时这两个值为空。
- 已加工未出货 = max(累计加工 - 累计出货, 0)，包括分批出货。出货超过加工，或加工/出货超过计划时标记数量异常，暂停推荐出货数量。这里是账面数，出货前仍需核对实物、质检与实际可发条件。

## 后台与助手

`GET /api/miniapp/workbench?view=risks|todos|shipments&page=1&query=`。

仅接受 Bearer 会话；服务端从会话获取 workspaceId，客户端和模型都不能指定工厂。数据库在 RepeatableRead 事务中读取订单并聚合加工/出货数量。接口不包含客户、价格、备注或账号信息。免费 factoryProxy 已加入该只读路径及参数白名单。

助手 lookup_progress 的 kind 新增 risks、todos、shipments，复用同一服务。返回完整匹配汇总及最多 12 张订单来源卡；有更多时明确 hasMore，模型不能用卡片数代替总数。沿用服务端 gpt-5.6-luna 配置和异步任务机制。按用户后续要求，前端查询时不再弹出中转确认，直接发送；后台调用配置和只读权限不变。

示例：`今天有哪些交期风险和待办？`、`列出待出货清单`、`CNC-01 有哪些逾期订单？`。

此次无数据库结构变更、迁移和种子执行。更新后台镜像时必须覆盖默认 entrypoint 为 npm run start，防止默认启动脚本运行 seed。部署前后用 scripts/audit-factory-business.cjs 比较所有工厂业务表摘要；会话登录变化不计入业务摘要。仅新增小程序 API 和小程序页面，不改网站 React 页面。

服务器访问 Google Fonts 曾超时。部署时可从已有镜像复制 `.next/static` 到构建阶段的 `/factory-fonts`，并在该次 `npm run build` 设置 `NEXT_FONT_GOOGLE_MOCKED_RESPONSES=/app/deploy/production/offline-fonts.cjs`。该适配器只读取已有的真实字体 CSS 和 woff2 字节，缺文件立即失败；没有占位字体，也不改网站页面源码。该变量仅用于构建，不传入运行容器。

验证包括北京时间边界、分批数量、异常/无计划、任务去重、完整汇总和分页、会话隔离、代理白名单与小程序迟到响应隔离。线上联调仅用新演示工厂，不录入或修改锦强数据。
