# 订单图纸图片预览与机器多订单关联设计

## 背景

当前订单详情页把已上传图纸按目录树展示，但点击文件只会通过鉴权接口下载，无法直接查看图片。机器侧则使用 `Machine.currentOrderId` 保存唯一的当前订单，录入加工或出货记录时，后端自动把记录写入这个订单。因此，一台机器不能同时保留多个未完成订单，也无法在一次录入前明确选择目标订单。

本次改造解决两个现场操作问题：用户可以在订单详情中直接预览并连续切换多张图片；一台机器可以同时关联多个未完成订单，操作员录入加工和出货时明确选择对应订单。

## 目标

- 点击订单中的图片文件时，在当前页面弹窗预览。
- 同一订单上传多张图片时，可通过按钮或键盘在所有可预览图片间切换。
- 非图片文件继续保持原有下载行为。
- 一台机器可同时关联多个未完成订单，一个订单也可关联多台机器。
- 录入加工或出货记录时必须明确指定已关联的目标订单。
- 已完成订单退出机器的可录入订单列表，并继续受到后端写入保护。
- 保留现有生产记录、订单汇总、经营分析以及 workspace 隔离。

## 非目标

- 不预览 PDF、STEP、DWG、DXF、压缩包或其他非图片文件。
- 不做 CAD 转图片、图片标注、旋转、裁剪、缩略图生成或图纸版本历史。
- 不允许机器给未关联订单录入生产记录。
- 不改变加工和出货拆成两条 `ProductionRecord` 保存的现有规则。
- 不改变现有角色边界：经理创建和编辑订单；员工仍可在机器页面关联订单并录入生产记录。

## 总体方案

机器与订单采用显式多对多关联表，不再使用机器级别的唯一“当前订单”。生产记录创建接口同时接收 `machineId` 和 `orderId`，并在数据库事务内验证关联关系和订单状态。

图纸预览采用项目内置的轻量弹窗组件。订单详情页把可序列化的图纸列表传给客户端图库组件；图片通过现有 workspace 鉴权接口的预览模式加载，不引入第三方图库依赖，也不公开存储路径。

## 数据模型

新增 `MachineOrderAssignment`：

- `workspaceId`
- `machineId`
- `orderId`
- `createdAt`
- 复合主键：`workspaceId + machineId + orderId`
- 按 `workspaceId + machineId` 和 `workspaceId + orderId` 建索引
- 机器或订单删除时级联删除关联行

关联表同时使用 workspace 范围内的机器和订单复合外键，数据库层保证不能建立跨 workspace 关联。

现有模型调整：

- 从 `Machine` 删除 `currentOrderId` 和 `currentOrder`。
- `Machine` 新增 `orderAssignments` 关系。
- 从 `Order` 删除基于 `currentOrderId` 的 `currentMachines` 关系。
- `Order` 新增 `machineAssignments` 关系。
- `ProductionRecord` 结构不变，继续直接保存 `workspaceId`、`machineId` 和 `orderId`。

关联记录作为历史关系保留。订单完成后不删除关联；查询机器可录入订单时只返回状态不是 `completed` 的关联订单。订单恢复为 `in_progress` 后，会自动重新出现在原关联机器的可选列表中。

## 数据迁移

数据库迁移按以下顺序执行：

1. 创建 `MachineOrderAssignment`、复合外键和索引。
2. 将所有非空 `Machine.currentOrderId` 转为关联记录，包括指向已完成订单的记录。
3. 使用复合主键消除潜在重复关联。
4. 删除 `Machine.currentOrderId` 的旧外键、索引和字段。
5. 保留所有 `ProductionRecord`，不重算、不删除已有加工、出货和经营数据。

生产部署继续使用现有 `prisma migrate deploy` 流程。迁移完成后，服务查询只读取新关联表，不保留双写过渡状态。

## 机器与订单服务

### 添加关联

新增或改造关联服务，使其在事务内：

1. 按固定顺序锁定机器和订单。
2. 校验两者存在且属于当前 workspace。
3. 拒绝关联 `completed` 订单。
4. 通过 upsert 建立关联；重复提交按成功处理。
5. 如果订单状态为 `development_pending` 或 `processing_pending`，将其改为 `in_progress` 并清空 `closedAt`。

新建订单时仍可选择多台机器，但不再排除已经关联其他未完成订单的机器。创建订单和建立所选机器关联保持在同一事务内。

### 移除关联

移除关联只删除 `MachineOrderAssignment`：

- 不删除、迁移或修改已有生产记录。
- 移除后，该机器不能再给该订单创建新记录。
- 重复移除返回明确的“关联不存在”，避免界面误报成功。
- 添加和移除关联沿用当前机器页面权限，经理和员工均可操作。

### 创建生产记录

`CreateProductionRecordInput` 增加必填 `orderId`。服务在事务内：

1. 校验记录时间以及加工、出货数量。
2. 按固定顺序锁定机器和订单。
3. 校验机器、订单和 workspace。
4. 校验对应 `MachineOrderAssignment` 存在。
5. 拒绝状态为 `completed` 的订单。
6. 按现有规则将正数加工量和正数出货量分别创建为独立记录行。

订单完成、移除关联和创建生产记录使用一致的锁顺序。订单状态更新为 `completed` 时也必须在事务内锁定订单，保证“完成”和“录入”并发发生时，不会产生完成后的新记录。

更新和删除已有生产记录继续以记录自身的 `orderId` 为准，不受机器当前选择影响，并继续禁止修改已完成订单的记录。

## 机器页面交互

### 机器详情

“关联订单”区域改成未完成关联订单列表。每项显示：

- `客户名称 / 工件名称`
- 订单状态
- 计划量、加工量和出货量进度
- 进入订单详情的链接
- 移除关联操作

列表下方提供“添加关联订单”表单。下拉框只显示当前 workspace 内尚未与该机器关联且未完成的订单；没有候选订单时显示说明文本。

“录入记录”表单新增必选的“目标订单”：

- 只有一个可录入订单时自动选中。
- 有多个可录入订单时默认显示“请选择订单”，不隐式选择第一项。
- 没有可录入订单时禁用记录时间、数量、备注和提交按钮。
- 订单选项使用 `客户名称 / 工件名称`，避免依赖页面上不展示的内部订单号。
- 保存成功后返回当前机器详情页，并通过查询参数保留刚才选择的订单，便于连续录入。

### 机器列表

机器列表的“当前订单”改为“关联订单”。列表只统计未完成关联订单，展示数量和有限的名称摘要；订单较多时显示“另有 N 个”，完整列表在机器详情中查看。单台机器不再展示唯一当前订单的整体进度条。

### 订单页面

- 新建订单的机器选择器包含所有机器，不再因为机器已有关联订单而排除。
- 订单详情的“当前关联机器”改为“关联机器”，读取关联表展示机器。
- 已完成订单可以继续显示历史关联机器，但不能新增关联或生产记录。
- 现有“做过此订单的机器”仍从 `ProductionRecord` 推导，含义和展示保持不变。

## 图纸图片预览

### 可预览类型

第一版支持以下安全位图扩展名，并映射到固定响应 MIME：

- `.jpg`、`.jpeg` → `image/jpeg`
- `.png` → `image/png`
- `.webp` → `image/webp`
- `.gif` → `image/gif`

不预览 SVG，避免把可能包含脚本或外部资源的矢量文件放入内联展示上下文。未知扩展名、扩展名与允许类型不匹配以及所有非图片文件继续下载。

### 组件边界

新增客户端组件 `OrderDrawingGallery`，接收当前订单的完整图纸元数据数组，并负责：

- 按 `relativePath` 构建和渲染现有目录树。
- 保留目录 zip 下载和全部图纸下载入口。
- 为图片渲染预览按钮和独立下载入口。
- 为非图片渲染原有直接下载链接。
- 管理弹窗打开状态、当前图片下标、键盘事件和加载错误。

订单详情页继续作为服务端组件获取订单数据、处理权限和渲染其他业务区域。预览状态被隔离在图库客户端组件内。

### 排序与切换

可预览图片从当前订单的全部图纸中过滤，并按文件树使用的 `relativePath` 顺序排列，不受所在文件夹限制。

弹窗显示：

- 自适应视口的大图，保持原始宽高比。
- 当前文件名。
- “第 X 张 / 共 Y 张”。
- 上一张、下一张、下载和关闭按钮。

支持键盘 `ArrowLeft`、`ArrowRight` 和 `Escape`。第一张禁用“上一张”，最后一张禁用“下一张”，不循环跳转。切换图片时清除上一张的加载错误状态。

弹窗打开后锁定背景滚动并把焦点移入弹窗；关闭后把焦点还给触发预览的文件按钮。遮罩点击和关闭按钮均可关闭弹窗。

### 文件接口

现有 `GET /api/order-drawings/[id]` 增加 `preview=1` 查询参数：

- 两种模式都要求有效登录并按 `workspaceId` 查询图纸。
- 默认模式继续返回 `Content-Disposition: attachment`。
- 预览模式只接受允许的图片类型，返回固定图片 MIME 和 `Content-Disposition: inline`。
- 预览响应添加 `X-Content-Type-Options: nosniff` 和私有缓存策略。
- 非图片请求预览模式返回 415，不回退成任意内容的内联展示。
- 文件不存在或不属于当前 workspace 返回 404，不暴露存储路径。

图片解码失败时，弹窗显示“图片加载失败”，并保留下载当前文件的操作。

## 错误处理与一致性

- 前端下拉框只改善操作体验，所有 workspace、关联和订单状态约束都由后端重新验证。
- 已完成订单、已移除关联或来自旧页面的记录提交返回明确业务错误，不创建部分记录。
- 同一次表单同时填写加工和出货时，两条记录在一个事务内全部成功或全部失败。
- 关联添加幂等，避免重复点击产生复合主键错误。
- 图片预览加载失败不影响文件下载，也不影响继续切换其他图片。
- 上传和覆盖图纸行为保持现状；预览只作用于已经成功保存的文件。

## 测试策略

### 服务和集成测试

- 一台机器关联多个未完成订单。
- 一个订单关联多台机器。
- 重复关联保持幂等。
- 新建订单可以选择已经关联其他订单的机器。
- 记录按显式 `orderId` 写入正确订单，两个订单的汇总互不串单。
- 未关联订单、跨 workspace 订单和已完成订单不能录入。
- 移除关联后不能新增记录，既有记录和汇总保持不变。
- 完成订单后退出可录入列表；恢复为 `in_progress` 后重新可选。
- 完成订单与录入记录并发时，不产生完成后的新记录。
- 迁移后的历史关联和生产记录可正常查询。

### 页面和组件测试

- 机器详情展示多个关联订单及添加、移除入口。
- 多个订单时录入表单不会默认选择第一项；单个订单时自动选中。
- 无可录入订单时表单禁用。
- 机器列表展示关联订单数量和摘要。
- 订单创建器不再排除已关联其他订单的机器。
- 图片点击打开正确弹窗并显示计数。
- 按钮和键盘可以前后切换，首尾状态正确。
- `Escape`、关闭按钮和遮罩可以关闭，焦点正确恢复。
- 图片失败状态可见且下载仍可用。
- 非图片文件不出现预览入口。

### 路由和端到端测试

- 未登录不能下载或预览图纸。
- 跨 workspace 不能读取图纸。
- 图片预览返回正确的 inline、安全和缓存响应头。
- 非图片预览返回 415，普通 attachment 下载不受影响。
- E2E 将同一机器关联两个订单，分别录入加工和出货，并核对两个订单汇总。
- E2E 上传多张 JPG/PNG，点击任意一张后完成左右切换和下载验证。

最终验证运行单元/集成测试、页面测试、端到端测试、lint 和生产构建。

## 验收标准

- 同一订单上传至少两张图片后，任意图片均可弹窗显示，并能切换到上一张或下一张。
- 非图片图纸仍能按原方式下载，目录和全部图纸 zip 下载保持可用。
- 同一台机器可同时看到并管理至少两个未完成关联订单。
- 操作员可以在录入表单中选择目标订单，加工和出货准确计入所选订单。
- 完成订单后无法新增、修改或删除其生产记录；恢复订单后原机器关联重新可用。
- 现有历史生产记录、订单进度和经营统计在迁移后保持一致。
