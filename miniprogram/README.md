# 微信小程序 Demo（免费云函数转发）

原生微信小程序，无需安装前端依赖或编译。默认先展示虚构的「精工精密」公司介绍；访客不读取任何工厂业务数据。登录后使用工厂助手、机器和订单查询、订单详情与记录、按机器关联订单录入加工/出货、退出登录。经理可以看订单单价，员工接口不返回价格。平台管理员 `/admin` 账号不用于这里登录。

## 公司首页与工厂助手

- 首页是虚构制造企业介绍，展示五轴联动、精密车削、车铣复合、材料能力、首件/巡检/出货复核、应用行业和制造合作；不介绍小程序功能。顶部与页尾的员工入口进入登录页，业务页面即使被直接打开也仍需登录。
- 登录后默认进入「工作台」，底部可切换工作台、助手、机器、订单、我的；公司介绍可从「我的」查看。退出后回公司首页。
- 助手支持自然语言和连续追问，例如「1 号机今天加工多少？」「订单 ORD-xxx 的出货进度？」。模型调用服务端只读查询工具，回答附机器/订单原始数据卡，可点开原详情。
- 当前按用户指定使用 LINX2 的 `gpt-5.6-luna`，通过 Responses API 调用。密钥只放原服务器环境变量，客户端不能选择模型地址、密钥、工厂或任意工具。
- 按用户要求，助手发送问题时直接查询，不显示中转名称或首次确认弹窗；沿用后台已启用的模型配置，调用协议保留 consent:true 兼容字段。问题、最近对话与查询到的精简进度仍由服务器发送给配置的模型中转及其模型服务。工具不返回客户名称、价格、备注、密码或登录令牌；不提供写入工具，原加工/出货录入方式保持不变。
- 原网站前端无需修改。后台新增 `/api/miniapp/assistant`（状态 / 创建任务）和 `/api/miniapp/assistant/jobs/:id`（读取结果），数据库结构不变。通过短请求轮询适配现有免费转发函数 3 秒限制，模型任务在原服务器执行，整体模型超时 60 秒。
- 对话仅保留在当前小程序页面内存，服务端任务 10 分钟后不可读取（创建/读取请求会清理过期项）；重启会丢失未完成任务。本 Demo 使用单 Node 进程的临时任务存储，不适合直接扩展多副本。

服务端需要设置 `FACTORY_AI_BASE_URL`、`FACTORY_AI_API_KEY`、`FACTORY_AI_MODEL=gpt-5.6-luna` 与 `FACTORY_AI_DATA_SHARING_ENABLED=true`；未配置时明确显示未接入，不伪装模型回答。配置必须写入服务器忽略的 `.env.production`，不能放在小程序或 Git。启用模型会消耗中转账号的 API 额度，不属于腾讯云免费额度。

当前默认通过腾讯云免费环境提供的 HTTPS 网关调用普通云函数 `factoryProxy`，访问原服务器，与网站使用同一数据库。正式 AppID 为 `wxaad3cf2f0c22bfe6`，云环境为 `factory-miniapp-d2f8yb6s0afa796d`。由于该环境为 PG 模式，不支持从微信开发者工具导入，使用 `connection.mode: 'gateway'` 而非 `wx.cloud.callFunction`。管理员需要将 `config.js` 中 URL 的 HTTPS 主机加入微信后台的 request 合法域名，再做手机扫码验收；不需要购买域名。部署与免费期限见 [云函数接入文档](../docs/deployment/wechat-cloudbase.md)。以下 IP 调试步骤仅在主动将 `connection.mode` 改为 `http` 时适用。

## 1. 启动 / 更新同一个后台

小程序访问本仓库新增的 `/api/miniapp/*`，数据库、账号及生产记录与网站完全共用。无数据库结构变更。

- 本地开发：按根目录 README 启动 PostgreSQL 和 `npm run dev`（本项目默认监听 `0.0.0.0:3000`）。
- 已有服务器：将本次代码更新到服务器，沿用 `scripts/deploy-production.sh` 重建启动。仅导入小程序、没有更新服务器会出现接口 404。
- 保留已有数据库和客户账号。不要为了小程序重新 seed 生产库。
- 通过网站经理账号创建机器和订单，并把未完成订单关联到机器。也可使用已有业务数据。

## 2. 导入微信开发者工具

1. 导入本仓库的 `miniprogram` 目录，而不是仓库根目录。
2. `project.config.json` 已使用正式 AppID `wxaad3cf2f0c22bfe6`。使用具备该小程序预览权限的微信登录开发者工具。
3. 默认网关模式保持 `urlCheck: true`，并保留合法域名校验。管理员已添加腾讯云网关的 request 合法域名。
4. 无需“构建 npm”。点击“预览”生成二维码，手机扫码后输入网站客户账号密码。默认网关模式不显示服务器地址。

## 3. 手机扫码体验与 IP 调试

默认网关模式：用有预览权限的微信扫描开发者工具生成的二维码，使用网站客户账号登录，无需开启手机调试。预览码会过期，失效时重新点击“预览”。给其他人体验需依微信平台要求添加体验成员、上传并设置体验版；当前未提交审核或正式发布。

以下仅适用于主动切换 HTTP 的开发调试：

- 使用开发者工具的“真机调试”或有权限的“预览”扫码，在手机的小程序菜单中开启调试；必要时退出再进入。
- 电脑上关闭域名校验不代表手机会自动关闭。IP + HTTP 方案仅用于开发调试，不是正式发布配置；请用目标手机验证。
- 手机的 `127.0.0.1` 指向手机自身，不是电脑或云服务器。
- 本地调试确保手机和电脑可互访、端口未被防火墙拦截；WSL 开发时还需确保 Windows 到 WSL 的局域网转发可用。
- 公网调试确保服务器安全组放行现有网站端口（默认 18080）。先用手机浏览器访问同一个地址的 `/login`，确认连通。

## 4. 双端演示流程

1. 网站：经理创建订单和机器，关联订单。
2. 小程序：同一工厂账号登录 → 机器 → 选择机器 → 选择关联订单。
3. 输入本次加工 / 出货数量，核对弹窗后提交。两项可同时录入，至少一项大于零。
4. 网站：刷新 `/records`、订单详情或机器详情，确认数量与操作人。
5. 网站录入或修改数据后，小程序下拉刷新；切回列表 / 详情也会刷新。没有实时推送。
6. 已完成订单无法继续录入；关联关系或订单状态发生变化时，以服务端校验为准。

提交不会自动重试。点击期间按钮锁定；若超时或服务器错误，结果可能未知，页面锁定再次提交，请先在网站核对是否已写入，再退出页面决定是否重录。本 Demo 未实现跨请求幂等键。

## 接口

所有返回均为 JSON、`Cache-Control: no-store`。业务请求使用 `Authorization: Bearer <token>`，不依赖浏览器 Cookie。

- `POST /api/miniapp/auth/login`：`{ username, password }` → `{ token, user }`
- `GET /api/miniapp/auth/me`：当前账号
- `POST /api/miniapp/auth/logout`：撤销当前令牌
- `GET /api/miniapp/machines` / `GET /api/miniapp/machines/:id`
- `GET /api/miniapp/orders?query=&status=` / `GET /api/miniapp/orders/:id`
- `POST /api/miniapp/records`：`{ machineId, orderId, completedQuantity, shippedQuantity, notes? }`

工厂归属和操作人来自服务端登录态，不能由客户端指定。录入时间采用服务器当前时间。过期 / 撤销令牌返回 401 并返回登录页。网站继续使用原 Cookie 登录。

HTTP 调试会明文传输凭据，只使用演示账号和演示数据。默认网关模式通过 HTTPS 调用免费普通云函数，不使用 AnyService；云函数到当前 HTTP 源站的链路仍未加密，不能视为全链路加密。网关和函数均不重试写入，超时或 5xx 后须先核对网站记录再继续提交。

## 开发验证

在仓库根目录运行。数据库测试应指向专用测试库，不要指向业务库。

```bash
npm run test:run
npx tsc --noEmit
npm run build
# HTTP 联调（启动本地网站，验证小程序录入后网页能显示记录）：
npm run test:e2e -- tests/e2e/miniapp-api.spec.ts --project=chromium-desktop
```

`tests/integration/miniapp-flow.test.ts` 使用真实 PostgreSQL 验证双端业务层数据、权限和令牌失效；`tests/miniapp/client.test.ts` 验证原生页面逻辑与网络处理。这些检查不能代替微信开发者工具编译和真实手机预览。
